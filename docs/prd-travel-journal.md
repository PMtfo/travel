# PRD：十一旅游公开站点

## 背景与目标

- 现状：行程来自苹果备忘录正文与内嵌图片信息，原内容是按日期排列的文字清单。
- 痛点：路线关系不直观、待办不可操作、无法形成适合公开分享的视觉成品。
- 目标：制作一个公开可见的地图旅行手账，既能在手机上查看，也能保存成 PNG 长图。

## 架构

- 规模：个人旅行的公开静态站点，不设账户、数据库或服务端。
- 输入：结构化逐日行程与待办数据。
- 处理：React 渲染、`localStorage` 保存 Todo 状态、浏览器端生成 PNG。
- 输出：Vite 静态构建产物，可部署到任意静态托管平台。
- 隐私底线：不展示旅客姓名、订单截图、订单号或其他身份信息。

## MVP 范围

### 必做

1. 完整覆盖 2026-09-24 至 2026-10-07，共 14 天。
2. 提供城市移动路线图与日期时间线。
3. 使用语义明确的交通、住宿、游览、待办图标。
4. Todo 可勾选、筛选、重置并在刷新后保留。
5. 一键导出主要行程为 PNG。
6. 响应式，无服务端依赖，支持公开静态部署。

### 非目标

- 不接入地图 SDK、账户体系、在线同步或订单系统。
- 不修改苹果备忘录。
- 本次不执行远程部署、Git 提交或推送。

## 技术方案

- Vite + React + TypeScript
- `lucide-react` 提供图标
- 自定义 SVG 提供路线图与本地目的地插画
- `html-to-image` 生成 PNG；资源全部本地化，避免 Canvas 跨域污染
- CSS Grid / Flex + 640px、900px 响应式断点

## 成功定义

| 条件 | 验证方式 |
|---|---|
| 14 天行程无缺日 | 数据检查与页面走查 |
| 路线与时间线手机可读 | 390px 视口截图走查 |
| Todo 操作并持久化 | 浏览器勾选、筛选、刷新与重置 |
| PNG 可下载 | 浏览器点击导出并检查下载文件 |
| 可静态部署 | `npm run build` 成功 |
| 公开版隐私合规 | 搜索姓名、检查图片与页面文本 |
